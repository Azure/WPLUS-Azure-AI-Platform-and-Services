# Quick Start Guide - Microsoft Foundry

## Introduction 

This lab is completed by running the `setup and quick_start.ipynb` Jupyter notebook. The notebook introduces Microsoft Foundry through an end-to-end exercise: authenticate with Azure, connect to a Foundry project, call a deployed model, and create an agent that calculates and visualizes BMI.

## Objectives 
By completing the notebook, you will:
- Authenticate to Azure from Visual Studio Code
- Initialize an `AIProjectClient`
- Send a chat completion request to a deployed model
- Create a prompt agent with Code Interpreter
- Download an image generated by the agent
- Clean up the agent and conversation resources

## Estimated Time 

30 minutes 

## Prerequisites
Before opening the notebook, confirm that:
- You completed the environment setup from the previous lab.
- A Microsoft Foundry project has been provisioned.
- Your account has the **Foundry User** role for the project. See [Microsoft Foundry RBAC documentation](https://learn.microsoft.com/azure/foundry/concepts/rbac-foundry).
- The repository-root `.env` file contains:
   - `TENANT_ID`
   - `AI_FOUNDRY_PROJECT_ENDPOINT`
   - `MODEL_DEPLOYMENT_NAME`
- The Python environment includes `azure-ai-projects>=2.6.0,<3.0.0` and the other packages listed in the repository-root `requirements.txt` file.
- You are signed in to Azure CLI. In the VS Code terminal, run:

   ```powershell
   az login --use-device-code
   ```

   Open the displayed URL, enter the device code, sign in with your lab credentials, and select the default subscription when prompted.

## Run the Notebook

1. Open `setup and quick_start.ipynb` in this folder using VS Code.
2. Select the Python kernel that contains the packages from `requirements.txt`.
3. Run the notebook cells in order from top to bottom.
4. Read the output after each code cell and resolve any reported configuration or permission issue before continuing.

Running cells out of order can leave required variables or clients undefined. Restart the kernel and run all cells again if the notebook state becomes inconsistent.


## Code Cell Guide

### Cell 4 - Load Configuration and Authenticate

Imports the required libraries, searches the notebook directory and its parent directories for `.env`, and loads its values. It then:

- Reads `TENANT_ID`
- Creates an `AzureCliCredential` scoped to that tenant
- Requests a Microsoft Foundry access token to verify authentication
- Reports clear errors when `.env`, `TENANT_ID`, or Azure CLI authentication is unavailable

Expected result: `Successfully authenticated with Azure CLI!`

### Cell 7 - Create the AI Project Client

Loads `AI_FOUNDRY_PROJECT_ENDPOINT` from `.env` and creates an authenticated `AIProjectClient`. This client is used by the remaining code cells.

Expected result: `Successfully initialized AIProjectClient`

If this cell reports an error, verify the endpoint in `.env`, the selected Azure subscription, and your project role assignment before continuing.

### Cell 9 - Send a Chat Completion

Creates the OpenAI client and sends a short health-related prompt through the chat completions API. It prints the model's response and provides troubleshooting guidance if the request fails.

Expected result: a one-sentence response about staying healthy.

### Cell 11 - Create and Run the BMI Agent

Creates a versioned prompt agent using `MODEL_DEPLOYMENT_NAME` and enables the Code Interpreter tool. The cell then:

- Creates an OpenAI conversation
- Requests a BMI calculation for a 5-foot-4-inch, 130-pound person
- Asks the agent to generate a BMI scale visualization
- Prints the agent's response
- Downloads generated files referenced by the response
- Saves the PNG file in the notebook folder
- Deletes the agent version and conversation

Expected result: a BMI analysis in the output and a generated PNG visualization in this folder.

## Troubleshooting

- **`.env` not found:** Complete Lab 00 and place `.env` in the repository root.
- **Azure CLI authentication failed:** Run `az login --use-device-code --tenant <TENANT_ID>` in the VS Code terminal, then rerun Cell 4.
- **Project client initialization failed:** Verify `AI_FOUNDRY_PROJECT_ENDPOINT` and confirm that your account has access to the project.
- **Model request failed:** Verify that `MODEL_DEPLOYMENT_NAME` exactly matches a deployed model and that your role permits model access.
- **Agent or Code Interpreter failed:** Confirm that the selected model supports the agent scenario and that Agent Service and Code Interpreter are available for the project.

## Expected Results

After running the complete notebook, you should have:

- An authenticated connection to Microsoft Foundry
- A successful chat completion response
- A successful BMI agent response
- A locally saved PNG visualization
- No remaining agent version or conversation created by the exercise
